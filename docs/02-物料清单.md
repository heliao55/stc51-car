## 采购原则

1. **先补齐「能让电机转」的最小集合**：电机 + 驱动 + 电源。这三样不全，后面全是空转。
2. 传感器最后买：先把车能直着走，再谈循迹。
3. 同一家店买齐，省邮费；单价差几块钱不值得分三家。
