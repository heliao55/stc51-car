# 01 硬件与接线

## 1. 需要的东西

- 51 最小系统板（STC89C52RC）
- CH340 USB-TTL 模块（3.3V/5V 可选，接 **5V**）
- 杜邦线 4 根

## 2. 接线表（下载 / 串口）

| USB-TTL | 51 最小系统板 | 说明 |
| --- | --- | --- |
| TXD | **P3.0 / RXD** | 交叉！下载器的发接收片的收 |
| RXD | **P3.1 / TXD** | 交叉！下载器的收接收片的发 |
| GND | **GND** | 必须共地，不共地一切免谈 |
| 5V | VCC（可选） | 板子已有独立供电时**不要**接，避免双电源打架 |

⚠ 三条最常见的错：
1. **TX/RX 没交叉**（对插）→ STC-ISP 一直「正在检测目标单片机…」
2. **没共地** → 同上，或者能识别但下载校验失败
3. **芯片插反 / 没插**（裸板）→ 完全无响应

## 3. STC-ISP 下载步骤

1. 单片机串口选 CH340 对应的 COM 口（设备管理器里看）
2. 波特率先选 **2400**（第一次求稳，通了再提到 115200）
3. 打开 `.hex` 文件
4. 点「下载/编程」
5. **给单板上电**（冷启动）——这一步是必须的，STC 的 ISP 只在复位瞬间握手
6. 出现「操作成功」后，程序开始跑

> 如果第 5 步之后一直卡在「正在检测目标单片机」：断一下电，重新点下载，再上电。别反复点，先查接线。

## 4. 晶振与波特率

最小系统板一般是 **11.0592MHz** 或 **12MHz**，板子上印着。
- 11.0592MHz：串口波特率能整除，误差小，**优先用它**
- 12MHz：9600 波特率有约 8% 误差，能通但不稳

写串口代码前先确认板子上的晶振丝印。

## 5. 引脚使用约定（本项目）

| 用途 | 引脚 | 备注 |
| --- | --- | --- |
| 下载 / 串口 | P3.0、P3.1 | 被占用，不能再当普通 IO 用（除非分时） |
| 调试 LED | P1.0 | 板上或外接，低电平点亮（多数最小系统板如此，以实测为准） |
| 电机 PWM | 待定 | 定时器 |
| 循迹输入 | 待定 | 数字量或模拟量 |

> 引脚分配一旦定下就写进这张表。改一次引脚，所有代码和接线都要跟着改——这是最常见的返工来源。
