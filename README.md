# stc51-car —— 51 单片机循迹小车

> **目标**：2026-12-15 前，这辆车能自己循迹跑完一圈。
> **现状**：准备阶段（器件清点 + 工具链打通 + 点灯）。

项目定位：用最便宜、最笨的 51 把一辆车从零做出来。作用不是拿奖，是攒出第一次「从零做成一个东西」的经验。

## 里程碑

- [ ] **M1 点灯**：P1.0 上的 LED 按 1Hz 闪烁，证明「编译 → 下载 → 运行」整条链是通的
- [ ] **M2 串口**：单片机发数据，电脑串口助手收到（验证波特率、晶振）
- [ ] **M3 电机**：PWM 调速，前进 / 后退 / 差速转向
- [ ] **M4 循迹**：红外对管读黑线，单路能判断「在线 / 偏左 / 偏右」
- [ ] **M5 闭环**：五路（或三路）循迹 + 转向控制，跑完一圈

M1 之前的隐性前置：芯片插对方向、USB-TTL 的 TX/RX 交叉、共地。这三条错了，后面全白做。
